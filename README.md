\# LLM Video Summarizer



AI-powered YouTube Video Summarizer built using Streamlit, OpenAI API, and NLP techniques.



\## Features



\- Extracts YouTube video transcripts

\- Generates concise AI-powered summaries

\- Supports long-form video summarization

\- Interactive Streamlit UI

\- OpenAI LLM integration



\## Tech Stack



\- Python

\- Streamlit

\- OpenAI API

\- NLP

\- Transformers

\- YouTube Transcript API



\## Installation



```bash

git clone https://github.com/RuchiraDevane-dev/LLM-Video-Summarizer.git

cd LLM-Video-Summarizer



python -m venv venv

venv\\Scripts\\activate



pip install -r requirements.txt

```



\## Run Project



```bash

streamlit run app.py

```



\## Environment Variables



Create a `.env` file:



```env

OPENAI\_API\_KEY=your\_api\_key\_here

```
